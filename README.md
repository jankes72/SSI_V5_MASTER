# SSI V5 Master

SSI V5 Master is a Python architecture project for governed autonomous-system development. It separates reasoning, evidence, proposals, authority, execution, recovery and controlled software evolution.

## What is included

- Director/runtime orchestration and lifecycle contracts
- Governance, authority and proposal boundaries
- Agent, world, evidence, recovery and compute primitives
- Controlled Continuum engineering contracts
- Programmer Root control services
- Python test suites for the published modules

Some tests depend on operational configuration that is deliberately not published in this lightweight portfolio export.

## Architectural principles

- Proposal is not execution.
- Observation is not truth.
- Intelligence is not authority.
- Compute workers are not the control plane.
- Changes require tests, evidence and an authorized integration decision.

## Scope of this public repository

This is a lightweight source portfolio. It intentionally excludes local databases, model assets, virtual environments, API credentials, historical archives, generated caches and runtime data.

The project is under active development. Production deployment, external runtime adapters and autonomous integration remain explicitly controlled rather than automatic.

## Entry points

- `start_ssi.py` — primary SSI startup entry point
- `SSI_V5_RUN.py` — diagnostic/manual subsystem runner
